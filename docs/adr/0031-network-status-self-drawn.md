# 网络状态格自绘，不并入收编

用户需求：联网状态在任务栏右组常驻一眼可见。但 Windows 原生网络图标（同族的还有音量、电池这类系统图标）由系统任务栏自绘呈现，**不经 Shell_NotifyIcon 注册**——**收编**管线（TaskbarCreated 广播＋竞争窗）对它原理上不可达，无广播可响应、无注册可转发。故新增**网络状态格**：面板自绘（联网/断网二态），点击触发快速设置；联网判定取本机网卡快照（存在带 IP 的活动非内部网卡即联网），不发探测包。方向上与音量格（触发 Win+A）同款——系统级状态与浮层不复制、只补位触发。本 ADR 记录该约束，防止后人再尝试把系统级图标纳进收编管线。

## Considered Options

- **寻找系统网络图标的收编通路**——不可达：系统图标不走 Shell_NotifyIcon，无注册可截。
- **不自绘、依赖快速设置内查看**——被需求本体否决（常驻一眼可见正是需求），且快速设置入口本身也要先有格可点。
