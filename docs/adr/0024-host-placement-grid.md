# 桌面组件摆位：宿主统一网格、拒绝重叠、组卡冻结与展开临时模态

独立面板上的桌面组件位置此前是写死的：内核四卡（时钟/天气/日历/会话）的几何写在面板样式表里按 DOM id 匹配（ADR-0014 明记「内置卡片无布局表」），组卡位置由插件按视口自动居中现算，文档区原点来自 `config.desktop.docZone`。用户不能按使用习惯调整版面，但也不想要任意像素坐标——卡片互相压盖、边缘参差，桌面失去秩序。要的是**有约束的自由**：位置由用户定，但只能落在统一网格上。本 ADR 记录这次摆位能力的五个关键取舍。

## 前提

- 桌面组件大多是**插件包**（工单10 起）：内核四卡、搜索面板、日历、组卡都是渲染层里由插件自建的 `.card` 元素；宿主无法逐插件改布局代码。
- 卡片几何与热区申报共用 `getBoundingClientRect()`：位置写入必须与热区申报同源，否则用户看到的位置与能点的位置分家。
- 布局存储 `layout.json` 已有文档项摆位名单（工单06，`docs: string[]`）；本期必须在不丢旧顺序的前提下加卡片格点表。
- 面板是**单实例常驻**、任务栏是独立窗口；摆位只作用于面板窗，任务栏与设置浮层不参与。

## 决策

### 1. 宿主统一摆位，插件只决定尺寸与内容

位置由面板宿主持有：渲染层新增 `renderer/placement.ts`，自动登记窗口内全部 `.card`（身份优先级 `data-card-id` → DOM `id` → 宿主生成序号）与可见的文档区 `#doc-zone`；插件自算的位置/尺寸不再写内联样式，而是发布到 `data-placement-auto-*` 作为宿主的默认位来源（doc-group-cards 的 `layoutRow` 按 `document.documentElement.dataset.placementHost` 切换）。宿主独占内联 `left/top/width/height`；重排由 1Hz 快照、插件 `onDomChanged`、展开/收起与 resize 显式驱动——**不用 MutationObserver 盯 style/class**：宿主写样式会反过来触发观察者，形成「同步 → 写 DOM → 再同步」的空转（真机首轮实证：渲染层主线程被钉死）。尺寸仍由插件决定（组卡两态、搜索活动态、文档区随内容），宿主只把**插件卡**的渲染尺寸向上取整到 20px 整数倍；内置卡与组卡用固定量化表。

显式标记为浮层外壳的元素（组卡自绘菜单的全屏挡板 `data-placement-exempt`、设置卡、删除确认层）不登记、不摆位、不占位。任务栏是另一扇窗，不在本机制内；搜索面板活动态不长按。

**备选否决**：让每个插件自己实现拖拽与网格——插件生态手感不可能一致，新增插件还得逐家改布局代码；把位置写进每张卡的 CSS 类——无法表达用户手定位、也躲不开 1Hz 插件重绘；用原生 HTML5 拖拽——合成输入驱不动，且本面板已全局掐掉 `dragstart`（会冻住常驻面板）。

### 2. 20px 双轴格点、可用区与尺寸量化

- 网格步长 20px；位置以**格点**（`col/row`）存储，不以像素存储——分辨率变化不改变格点关系。
- 可用区 = 面板全屏减四周 40px、再减底边 64px 任务栏带；卡片落点夹取进可用区，四边对齐格线。任务栏收栏时仍保留同高带，版面不漂移。
- 尺寸量化表：时钟 320×180、天气 320×180、日历 320×300、会话 420×520、搜索待机 420×100（活动态高度随内容）、组卡折叠 320×240 / 展开 640×980、文档区宽 ≤640 高随内容。默认位同步网格化（左列 y=40/240/440，右列 y=40/160，文档区原点取 config 后量化）。
- 点阵网格只在长按成立后浮现（淡入淡出），铺满可用区；平时不打扰壁纸。

**备选否决**：自由像素坐标——用户明确不要「任意像素」的失序；按容器百分比定位——格点关系跨分辨率不稳定；把尺寸也交给用户拖拽缩放——版面会被弄散，本期不做卡片缩放。

### 3. 冲突即拒绝，不做自动避让

与任何已占矩形相交即判冲突：拖拽中落点预览变红，松手回弹原位（180ms），不写存储。新建卡（新插件卡、冻结后的新组卡）从屏幕中心向外找最近空位；桌面放不下时**拒绝并给出可见提示**，不静默叠卡、也不把已有卡自动搬走。只有在分辨率/面板尺寸变化时，手定位保留并夹取进可用区，夹取后仍相撞的卡才被挪到最近空位。

**备选否决**：冲突时自动推开邻卡——用户摆好的版面会被一次拖拽搅乱；允许重叠但用 z 序分层——桌面失去可读性，也违背「有约束的自由」；冲突时拒绝整次摆位但不回弹——用户看不到卡片去了哪。

### 4. 组卡默认位冻结；展开是临时模态

- 未冻结前，组卡维持插件按视口自动居中的位置（按格点量化）；**首次成功摆位任一张卡**时，把当时各张组卡的位置冻结为默认位。冻结后新增组卡落最近空位、解散一张不挪其他卡；未手定位的卡不写存储。
- 展开不写存储位置：以折叠位中心放大到 640×980，越界按可用区夹取（「原位」是保中心近似）；邻卡淡出，收起后复原；展开期间邻卡不响应摆位，展开卡自身仍可长按拖动（拖的是折叠基准位，写回存储的也是基准格点）。
- 搜索面板占用按待机矩形；活动态优先向下展开，下方空间不足时向上展开，始终留在可用区内；活动态可覆盖其他卡（临时视觉，不产生占位）。

**备选否决**：展开时跳到屏幕正中（旧行为）——用户摆好的版面会被打乱；展开写存储——一次查看动作改变持久布局；组卡永不自算位置——没用过摆位的用户看到的版面会与今天不同（「未冻结前维持自动居中」是兼容承诺）。

### 5. 布局存储升版 v2，只写手定位

`layout.json` 升为 `{ version: 2, docs: string[], cards: Record<string, { col, row }> }`：

- `docs` 语义不变（文档项顺序，旧版原样保留）；
- `cards` 只含**用户拖过**的卡（手定位）；未手定位走默认位表，条目按 id 长期保留（插件停用/卸载不删，回来仍回原位）；
- 旧版 v1 文件按空卡片表读入（自愈，不丢文档项顺序）；
- 恢复出厂同时清空手定位与文档项顺序；
- 写入经桥接方法 `desktop/set-card-slot` 落到数据面子进程的同一份存储；渲染层先乐观更新、回执对账，失败回滚并可见提示。

**备选否决**：另立一份 `placement.json`——恢复出厂与删除/重命名等既有动作要跨两份文件保持一致，必然漂移；把卡片位置写进 `config.json`——config 是用户手改的出厂配置，手定位是用户行为的结果；只存像素——分辨率变化后无法恢复格点关系。

## Consequences

- 摆位是宿主级能力，新增插件卡无需声明即有一致手感；插件作者只对尺寸负责。
- 摆位纯函数（网格、占用、最近空位、默认位）**没有单测**：本票只做真机验收电池，数学缺陷只能靠电池的几何断言暴露。这是用户明确接受的覆盖取舍（`docs/agents/battery-governance.md` 的「单测能覆盖的不进」在此被本票的显式裁决推翻，记录在案）。
- 新增摆位电池（`app/accept/placement.js`，六段，健康轮校准后预算 120s）；主电池 P2/P4 的时钟几何、P5.5 的布局存储形状、组卡电池 P179/P180 的整排/展开断言随宿主持有位置改写。
- 已知边界（不改，记录在案）：展开卡 640×980 时，1440 高屏的可用高为 1296，只有折叠位 y ≤ 356 的卡能完全原地展开，其余按「保中心 + 夹取」上移——「原位」是近似。组卡默认位冻结是**会话内状态**：layout v2 只持久化用户手定位，未拖过的组卡跨重启仍按视口自动居中（冻结不落盘，避免违反「只有手定位写入」）；插件在装时文档区隐藏、不占位，文档区摆位只对停用插件的用户可见；文档区后续内容变多压到卡片时不被自动推开。面板没有音频通道，摆位不做音效反馈，以视觉反馈为准。
- 内核文档区退役（用户已表达不再需要）不在本决策范围——它涉及桌面项渲染/选区/框选/拖拽整链与多块电池，另开票。

## 修订（2026-10-28，#317/#318 收口）

- **相撞消解只在启动与面板尺寸变化时执行**。文档区内容增长（宽度封顶、高度随内容）等非尺寸变化轮次里，手定位与默认位都固定不动，造成的相交**接受**——不把任何已摆好的卡自动推开。
- 面板尺寸变化：手定位按格点保留并夹取；夹取后与已占矩形相撞的卡挪最近空位；**仍无空位**时停靠首个可用位 `(0,0)` 并落 `placement-overlap-accepted` 诊断，不静默重叠（极端小面板下两张大于可用区的卡会如实告警）。
- 新卡/新组卡仍按「从屏幕中心向外找最近空位」；无空位**拒绝创建**并提示，现有版面不动。
- 插件卡尺寸变化由 `ResizeObserver` 即时跟踪（同一元素 observe 幂等；宿主写回同值不产生尺寸变化，故不会形成观察-回写回环），1Hz 快照与 `onDomChanged` 仍作兜底。
- 展开自首次使用起即「保中心放大」；#316 中「未摆位前展开居中」的表述由本 ADR 决策 4 与父票用户故事 28 覆盖，组卡电池 P180 已按原位展开改写。
- 摆位电池 P6 增补极端小面板（300×300、两张手定位均大于可用区）停靠与诊断断言；预算按健康轮校准为 120s。
