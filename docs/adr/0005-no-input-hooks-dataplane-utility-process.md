# 主进程不持有系统级输入钩子；周期采集整体移入数据面子进程

真机实测出现全系统鼠标卡顿（间歇阵发、退出面板即恢复、143Hz 屏感知明显）。根因链：穿透恢复用 `setIgnoreMouseEvents(true, { forward: true })` 使 Electron 在主进程线程装上全局 `WH_MOUSE_LL` 低级鼠标钩子——系统每个鼠标事件都串行等它返回；而同一条线程上的周期采集（每 1s 会话扫描 + 两个 SQLite 同步查询 + 桌面重扫 + 每 2s 全系统进程枚举 FFI）把事件循环**每秒阻塞约 300ms**（基线探针存证：140 秒内 ≥150ms 停顿 139 次、p99=367ms、最大 2302ms，与 1Hz tick 精确同相）。钩子让这些阻塞直接冻结全系统光标。为此立两条结构性红线：**窗口宿主线程不得持有任何系统级输入钩子**（穿透一律不带 forward，热区判定由主进程 25ms 光标轮询完成，悬停高亮由热区解除穿透后的真实事件驱动）；**周期数据采集不得跑在主进程事件循环上**——会话/硬件/使用日志/桌面承载四个采集服务连同定时器整体搬进 utilityProcess 数据面子进程（`src/main/dataplane.ts` 为入口，koffi/node:sqlite/fs 均为纯 Node 真源），主进程只留窗口/热区/桥接/插件宿主，经 `PanelDataPort` 接缝（进程内装配 LocalPanelDataService / 生产装配 DataplaneService）与桥接层解耦。lnk 目标解析、图标提取、桌面项启动是 Electron 主进程 API：解析经凑批 RPC 回填缓存（同拍去重 + 在途去重，晚到一拍只影响推荐序初值——与冷启动先验同款语义），图标由主进程按快照条目增量预热，启动按主进程手里的快照条目池校验后执行。附带：nvidia-smi TTL 3s→5s（spawn 节奏减半）、热区离开去抖（连续两拍）与重钉节流（500ms）。

## Considered Options

- **保留 forward，只优化主线程阻塞（治标）** —— 钩子仍在：未来任何一次主线程阻塞（新插件、同步 IO、GC）都会复发全系统卡顿；且全屏窗口让钩子把整屏每次鼠标移动复制进 Chromium 管线，纯亏。
- **forward 保留但只在「光标接近热区」的预测窗口临时挂载** —— 复杂度高、仍有钩子窗口期、省下的只是热区外的 `:hover` 高亮（对应元素本就不可点）。
- **worker_threads 而非 utilityProcess** —— 更轻，但 SQLite busy_timeout 堵 500ms、koffi 崩溃这类故障会与面板同进程同死；独立进程隔离更稳（崩溃按退避自动重启，摆位与使用日志都在盘上、重启即收敛）。
- **桌面承载扫描留在主进程（只给 lnk 解析接缓存）** —— 改动更小，但桌面扫描链（statSync×N + GetFileAttributesW + 编排重算）仍每秒占主进程，热区轮询与桥接推送的延迟底噪仍在。
- **渲染侧 mousemove → IPC 驱动热区（替掉主进程轮询）** —— 把高频输入流引回主进程 IPC，方向反了；25ms GetCursorPos 轮询单次微秒级，实测无害。

## Consequences

- 悬停高亮改由热区解除穿透后的真实事件驱动：进入热区后 ≤25ms 点亮（热区离开去抖再 +25ms），肉眼无感；冷却态不再有热区外高亮。
- dock 推荐序在启动后第一拍可能缺 UserAssist 目标匹配（lnk 解析异步回填），下一拍 1Hz 重算收敛——与既有「先验晚到几百 ms」语义一致。
- 数据面子进程崩溃：硬件历史环归零重来（展示性曲线，可接受），摆位/使用日志/会话扫描随子进程重启自然收敛；重启按 1s→30s 退避，事件经存证日志记账（dataplane-spawn/exit/ready-timeout）。
- 主进程首拍就位改为等子进程第一份快照（fork+boot ≈ 数百 ms；15s 超时放行降级，不拦桌面）。
- 内核测试装配不变：createKernel 仍进程内组装全部服务（经 LocalPanelDataService 出数据面端口），新增 createDataplaneKernel 供子进程入口与离线测试共用同一批服务类与依赖束缝。
- 代价：常驻多一个 Node 子进程（内存基线上升）；桥接数据段多一跳主进程转发（每秒一份结构化克隆快照，量级 KB，可忽略）。
