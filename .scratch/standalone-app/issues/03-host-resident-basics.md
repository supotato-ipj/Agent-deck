# 03: 宿主常驻件

**What to build:** 面板成为可日常共处的常驻件：托盘图标（含退出面板入口）、单实例守卫（重复拉起自动退出、不出现双面板）、Win+D 收起桌面后面板防抖自动恢复。用户视角：面板像壁纸一样常在，可从托盘管理，误触显示桌面不用找回。

**Blocked by:** 02 底座尖兵

**Status:** ready-for-agent

- [ ] 托盘图标常驻，菜单可退出面板；退出后托盘随之消失
- [ ] 二次拉起应用立即自行退出，屏幕上始终只有一个面板
- [ ] Win+D 后面板最小化，防抖窗口后自动恢复原位
- [ ] 三项行为纳入验收电池并截图存证于工单评论
