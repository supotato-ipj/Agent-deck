# Spec: 通用 deck 修缮——应用区真实图标、交互永不顶起与 Qoder 状态块退役

Status: ready-for-agent

## Problem Statement

用户把独立面板当通用桌面作战台在用，遇到了三件糟心事：

1. **应用区图标全空白**：dock 里每个应用快捷方式都只能看到一个通用空白快捷方式图标，认不出哪个是哪个。「每个桌面项显示真实图标、观感与原桌面无差」的承诺完全落空。
2. **交互即顶起**：开着别的窗口（非最大化、桌面可见）时，点击任何一个桌面组件、桌面项或文件，整个独立面板会浮到当前聚焦窗口上方，造成重叠、遮挡并干扰正在使用的窗口——从点击那刻到鼠标离开热区为止一直盖着，点完只用键盘不挪鼠标时盖得更久。
3. **Qoder 专属残留**：面板定位已是通用 deck，右列却仍有一块 Qoder 专属状态块，占着版面与通用定位不符。

## Solution

1. **真实图标**：应用区每个快捷方式显示其指向目标的真实图标。修法在提取层：对快捷方式先解析出图标源（优先快捷方式声明的图标定位路径，缺失则取目标可执行文件），再对本体提取图标；死链回落通用图标。附带改善：快捷方式图标以 48px 源提取，在 dock 的 40px 显示位上更锐。
2. **永不顶起**：独立面板永不因交互浮到任何窗口之上——面板窗口创建即不可激活（点击不激活、不顶起、不抢键盘焦点），既有各路钉底全部保留。需要键盘的场景（搜索输入、设置浮层 ESC）经「键盘模式」临时取得键盘焦点：开 = 临时可聚焦 + 聚焦 + 立即钉底，关 = 恢复不可聚焦 + 钉底；退出后键盘焦点悬空、不自动还原（与点击真实桌面同款语义）。
3. **Qoder 状态块退役**：卡片、快照数据段、插件能力一并移除；其版面由会话列表卡加高吞并（可见会话行约翻倍），硬件卡位置不动。Qoder 的会话行（QD 标签、运行状态、行内任务进度、点击直达/拉起）全部保留——那是五工具通用能力。

## User Stories

### 应用区图标

1. 作为桌面用户，我想让应用区的每个快捷方式显示其指向应用的真实图标，这样不读标签也能一眼认出入口。
2. 作为桌面用户，我想让快捷方式图标以高分辨率源提取，这样 dock 的 40px 显示位上不发虚。
3. 作为桌面用户，我想让死链（目标被卸载的快捷方式）显示通用快捷方式图标、提取失败的条目显示落位字形，这样桌面不因个别坏项破相。
4. 作为桌面用户，我想让快捷方式改指目标后面板在下次扫描时换上新图标，这样图标始终跟着指向走（既有行为，作为回归保障）。

### 交互永不顶起

5. 作为桌面用户，我想在任意窗口聚焦（非最大化、桌面可见）时点击任何桌面组件、桌面项或文件，独立面板都保持在这些窗口之下，这样面板永远不遮挡我正在用的窗口。
6. 作为桌面用户，我想点击面板内容时不抢走我工作窗口的键盘焦点，这样点一下桌面项后能继续盲打。
7. 作为桌面用户，我想点击搜索卡后键盘焦点进入搜索输入框、中文输入法可正常输入，这样搜索照常可用。
8. 作为桌面用户，我想在搜索激活（键盘模式）期间面板依然钉在所有窗口之下，这样打字时也不遮挡别的窗口。
9. 作为桌面用户，我想按 ESC 或点击别处退出搜索后，焦点处理与点击真实桌面一致（不自动还原到之前窗口），这样行为可预期。
10. 作为桌面用户，我想打开设置浮层时同样拿得到键盘（ESC 可关层、滑杆可拖），关闭后恢复不抢焦点，这样设置交互照旧。
11. 作为桌面用户，我想让面板被任何途径唤起（托盘、二次拉起、Win+D 防抖恢复）后依然钉底，这样任何路径都不破例。
12. 作为桌面用户，我想让拖拽摆位、双击启动、单击选中在「永不激活」下原样可用，这样肌肉记忆不受影响。
13. 作为五工具用户，我想点击会话行仍把对应工具窗口带到前台（那是工具窗口置前，不是面板置前），这样直达能力不受影响。

### Qoder 状态块退役

14. 作为通用 deck 用户，我想让右列不再有 Qoder 专属状态块，这样版面反映通用定位。
15. 作为通用 deck 用户，我想让会话列表卡加高补位，这样版面不留空洞、可见会话行更多。
16. 作为五工具用户，我想让 Qoder 的会话行继续出现在会话列表（QD 标签、运行状态、行内任务进度），这样 Qoder 可见性不因状态块退役而丢失。
17. 作为五工具用户，我想让 Qoder 会话行的点击直达/拉起照旧，这样工作流不受影响。
18. 作为插件作者，我想让插件能力表如实反映可读快照段（qoder 段移除后能力一并移除），这样能力声明不撒谎。

### 通用

19. 作为面板维护者，我想让验收电池守住「点击永不顶起」「键盘模式焦点到手」「不同快捷方式图标互不相同」三条防回归线，这样这三类缺陷不再复发。
20. 作为面板维护者，我想让词汇表与仓库导言如实反映现状（Qoder 状态块移入退役词汇、通用 deck 措辞），这样领域语言不与产品漂移。

## Implementation Decisions

- **快捷方式图标提取链**（工单01）：适配层提取器对快捷方式先经 shell 快捷方式解析取图标源——优先声明的图标定位路径、缺失或不可用回落目标可执行文件——再对本体做大尺寸提取；任一步失败回落现状（对 lnk 本体提取 = 通用图标）。图标源决策抽为纯函数（可离线测）。图标缓存键（路径+修改时间）与预热门机制不动——决策只住在提取器内部。
- **永不激活**（工单02）：面板窗口创建即不可聚焦（Windows 下等价无激活扩展样式）。保留全部既有钉底路径（启动首显、托盘/二次实例/Win+D 恢复、热区离开重钉），另加窗口获得焦点事件的兜底重钉。
- **键盘模式**（工单02）：走窗口宿主面新增「键盘模式开关」通道——与热区声明同属宿主机制、不进内核桥接契约（ADR-0004 的缝不变）。开 = 临时可聚焦 + 聚焦 + 立即钉底；关 = 恢复不可聚焦 + 钉底。搜索激活/退待机、设置浮层开/关四处接线。退出不自动还原焦点。
- **实施闸门**（工单02 前置）：第一步先在真机验证「不可激活窗口上点击后程序化聚焦能否稳定拿到键盘」（Windows 前台锁风险）。若被系统稳定拒绝：停下，带证据与用户重议；保底方案为「允许激活但点击即重钉」。
- **Qoder 状态块退役**（工单03）：内置卡片、快照 qoder 段、插件能力 'qoder'、状态计算及其专有辅助全部移除；五工具会话扫描器、行内任务进度、直达映射保留；会话列表卡吞并原状态块槽位，硬件卡位置不动。
- **词汇与导言**：词汇表开篇改为通用 deck 措辞（会话列表与硬件指标），「Qoder 状态块」移入已退役词汇并注明保留面（会话行）；仓库导言同步去掉「Qoder 任务进度」。

## Testing Decisions

- 好测试只测外部行为：快照形状（段的有无、会话行的保留）、桥接返回的图标区分度、真机 z 序与键盘焦点事实——不测内部调用序列与实现细节。
- 三条缝（已与用户对齐）：
  1. **真机验收电池**（最高缝，已有）：控制器上下文——合成输入 + 存证事件日志 + Win32 z 序自顶向下枚举 + 截屏 + 控制器内桥接调用。探针：聚焦窗口下点击热区 z 序始终在下；键盘模式焦点到手且面板钉底；不同快捷方式的图标 dataUrl 互不相等；Qoder 卡消失与会话卡补位。先例：02-pinned-bottom z 序探针、04-cards 截屏、05 桌面承载探针。实施闸门探针同走此缝。
  2. **内核桥接缝**（离线，已有）：注入假源 + 手动 tick 驱动内核，断言快照无 qoder 段、Qoder 会话行仍在、插件能力表无 'qoder'。先例：契约测试手动驱动内核的服务级 spec。
  3. **纯函数缝**（唯一新增，最小）：快捷方式图标源决策（图标定位优先 / 目标回退 / 死链回落）直接单测。先例：图标缓存注入提取器的 spec 形态。
- 真机电池与在跑面板共存（验收模式绕开单实例锁），不改变用户桌面偏好基线（既有前置/后置断言沿用）。

## Out of Scope

- 不做「退出键盘模式自动还原焦点到之前窗口」（已拍板不还原；将来要可再议）。
- 不做 .url 桌面项的图标定位解析（维持现状的关联图标回落）。
- 不动五工具会话扫描器、行内任务进度、点击直达——通用能力不在本次射程。
- 不为潜在第三方插件保留 qoder 数据段（彻底移除）。
- 不处理 Electron getFileIcon 的上游缺陷本身（不升级 Electron、不换图标库）——只在适配层绕行。
- 不重排右列其他卡片（硬件卡位置不动）。

## Further Notes

- **图标根因实证**（2026-09-30，探针产物在 `.scratch/icon-probe/`）：本机（Win11 26200 / Electron 44.4.3）`app.getFileIcon` 对所有 `.lnk` 返回字节级相同的通用图标（含现场新造的 notepad 快捷方式），对目标 exe/.ico 直取正常。已知上游限制：electron#15809、electron#18292。
- **z 序机制实证**：探针证明前台/激活态下底部重钉有效（窗口持键盘焦点的同时可钉底）——「键盘模式也钉底」的可行性依据。
- **键盘模式的前台锁**为本次最大不确定点，故设为实施闸门（见实现决策）。
- **决策记录**（grilling 共识，两轮）：永不激活（弃「允许激活但压底」）；键盘模式期间也钉底；退出键盘模式不还焦点；会话卡加高补位（弃硬件卡上移、弃留空）；彻底移除 qoder 数据段（弃只撤卡片）。
- 工单拆分建议：01 快捷方式图标、02 永不激活与键盘模式（含闸门探针）、03 Qoder 状态块退役。
