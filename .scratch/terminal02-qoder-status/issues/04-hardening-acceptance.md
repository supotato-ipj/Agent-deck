# 04: 容错与最终验收

**What to build:** 整套改造在异常环境下不伤害壁纸：Qoder 数据目录缺失或文件损坏时服务端优雅降级（返回空状态而非 500）；数据服务未启动时壁纸时钟/天气/日志照常工作；RUNNING 状态以闪烁高亮呈现、IDLE 为普通文本；活跃会话总数以角标显示；静默超过 90 秒后状态正确从 RUNNING 翻转为 IDLE。最终在 Wallpaper Engine 中由用户实际验收。

**Blocked by:** 03 QODER 状态区块垂直切片
