# 01: 测试基础设施 + 桌面项只读探针

**What to build:** 仓库当前零测试基础设施，本票先把它建起来（stdlib `unittest`，不引入 pytest），再交付一条**只读**命令：打印当前桌面上的全部图标项——显示名、项类型、当前坐标、快捷方式的目标路径。中文显示名必须正确，不得出现乱码。同时把 spec 留下的唯一未知量测定出来：图标格的**水平列步长**（此前只实测到垂直步长 98px），连同垂直步长一起固化为几何常量，供后续编排核心使用。

本票不写入、不移动任何东西。它是 Win32 读通道的打通与验证，也是后面所有票的地基。

**Blocked by:** None (can start immediately)

**Status:** claimed

- [x] 测试目录与运行方式建立，`unittest` 可一条命令跑起来，零新增第三方依赖
- [x] 只读命令列出全部桌面项，项数与实机一致（当前基线 14 项）
- [x] 中文显示名正确输出，不经由 shell/PowerShell 传递文件名
- [x] 每项能给出类型判定所需的原始信息（是否快捷方式、是否文件夹、是否系统隐藏项、是否回收站）
- [x] 快捷方式项能解析出其目标可执行路径
- [x] 采集范围同时覆盖用户桌面与公共桌面
- [x] `desktop.ini` 等隐藏系统项被识别出来（后续票会排除它们）
- [x] 水平列步长实测得出，与垂直步长一并写入几何常量
- [x] ctypes 调用为 64 位句柄显式声明了 restype/argtypes
- [x] 桌面图标视图句柄找不到时优雅报错而非崩溃

## Comments

- 2026-09-23: 由 to-tickets 创建。环境硬事实（图标层结构、跨进程内存分配、FFlags 现状）见 spec 的 Further Notes 与 ADR-0001。
- 2026-09-23: 实施完成。产物：`desktop_icons.py`（只读适配层 + 探针 CLI）、`zones_geometry.py`（几何常量）、`tests/`（stdlib unittest，24 个测试，运行命令 `python -m unittest discover -s tests -t .`）。
- 2026-09-23: 实施中修正三处事实，后续票须以此为准：
  1. **列步长实测 150、行步长 98**（由现有三列坐标 13/163/313 反推）。`LVM_GETITEMSPACING` 返回 (96,49)，与实际布局不符，**不可用作步长来源**；步长随最长标签宽度变化，几何常量是设计选择而非系统值。`--check-geometry` 改为从图标坐标反推步长再比对。
  2. **.lnk/.url 的显示名不带扩展名**（Explorer 永不显示 .lnk 扩展名），文件系统对齐必须同时按全名与 stem 建索引；kind 的后缀判定必须取文件系统路径而非显示名。
  3. 桌面内容会漂移：grilling 时的基线（Legavis.xlsx 等）已变为另一组文档，图标也不再是单列。编排核心不得假设任何具体文件名或单列布局。
- 2026-09-23: 回收站在本机显示为英文名 "Recycle Bin"（系统 UI 语言为英文），03 的归类规则不能只匹配中文"回收站"。
