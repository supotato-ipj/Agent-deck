# 02: 布局快照与一键还原

**What to build:** 交付"排错了能退回去"这个能力，它是整个功能敢被打开的前提。每次编排前自动留下一份布局快照（全部图标的显示名 → 坐标），存放在本地应用数据目录下服务的专属子目录；**出厂态快照必须在任何一次写入之前完成**，若已存在则永不覆盖。提供一条还原命令，可选择还原到出厂态或最近一次运行前态。

本票同时打通**落位写入**这条通道——通过 explorer 桌面图标视图写入坐标。它的第一次真实写入是"把图标还原回它们原本的位置"，这是所有可能的写入里最安全的一种，因此把最危险的未文档化接口放在这里单独验收。

- 2026-09-23: 运行前快照文件名加入微秒——秒级标签曾导致同一秒内两次快照互相覆盖（由测试抓到并修复）。
- 2026-09-23: 实机往返验证：index 0 图标 `(13,198)` → 写 `(1200,1200)` → 读回 `(1213,1178)`（吸附）→ `restore last` → 读回 `(13,198)`；counts=(14, [], [])。factory.json 在其后再次执行 snapshot 命令时 LastWriteTime 不变。
