验收路径：出厂态快照确认存在 → 首次全量 dry-run 并人工核对计划合理 → apply → 桌面截图核对分区观感 → 事件驱动增量验证（新建/删除文件）→ 还原到出厂态验证 → 确认 DECK 与数据服务既有能力零回归。

文档面向"三个月后的自己"：手钉清单怎么改、命令怎么跑、怎么还原、功能不工作时先查什么。
