# 08: 推荐位填补

**What to build:** 让应用区的空栏位被系统自动填上最常用的应用。编排核心新增一个输入：07 产出的频次分数。栏位分配规则变为——**手钉清单按顺序优先占据最靠前的栏位，剩余栏位由推荐按分数降序填补**。

三条不变量必须成立且被测试守住：

1. 推荐**只填空位，绝不顶替手钉**——用户钉住的东西永远不会被算法挤掉。
2. 12 个栏位被手钉钉满时，推荐自动不出现，应用区不溢出到别处。
3. 分数相同的候选按稳定次序排列，保证同样的输入总产生同样的计划（否则每次编排图标都会无意义地换位）。

**Blocked by:** 03, 07

**Status:** ready-for-agent

- [x] 编排核心接受频次分数作为输入
- [x] 手钉项始终占据最靠前的栏位，顺序与手钉清单一致
- [x] 剩余栏位按分数降序填补
- [x] 单测断言：任何情况下推荐项都不占据手钉项的栏位
- [x] 单测断言：手钉数 ≥ 栏位数时推荐结果为空，且计划总项数不超栏位上限
- [x] 单测断言：分数相同时次序稳定、可重复
- [x] 未进入排名（映射不上）的快捷方式仍按 03 的稳定次序占位，不因缺分数而被丢弃
- [x] dry-run 输出能区分某个栏位是手钉还是推荐，便于用户理解为什么它在那儿
