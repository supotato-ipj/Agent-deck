# 05: 验收电池——一键端到端主链路 + 截图存证

**What to build:** 仿照桌面分区验收电池先例的一键验收脚本，作为本功能后续回归的主缝：面板窗存在且几何落位 → 模拟点击激活 → 键入探针词 → 真实引擎返回结果 → 结果渲染断言 → Enter 打开验收专用的临时探针文件（造唯一名、搜它、验证已打开）→ Ctrl+Enter 验证资源管理器定位 → ESC/失焦退回待机态 → 全程截图存证并追加摘要到本票评论。临时探针文件与验收中打开的资源管理器窗口在结束后自动清理/关闭；脚本可重复执行（幂等），任一步失败即非零退出并报告失败步骤。

真机试跑（2560×1440@100% 时段）暴露并已修复三处真缺陷：
1. 裸 token 搜索引擎把同名探针**目录**排首位，Enter 开的是目录非文件；改搜
   完整文件名（含 .txt）后结果唯一且必首位（直连引擎实测）。
2. SendKeys 只进系统前台窗：ESC/粘词曾落进碰巧持焦点的其他窗口；现每次发键
   前物理点击面板 + 前台进程校验（`panel_sendkeys`）。
3. `wait_for` 成功返回 True、超时返回谓词值，类型不一致导致崩溃与假 PASS；
   统一返回最后一次谓词值，并加基线门防失锚。

另发现并规避一个环境级坑：Shell 的 MinimizeAll/UndoMinimizeAll 会把无框
面板一起卷进最小化-还原循环，还原时 Tk overrideredirect 窗口几何被重置
（实测 536×64+1982+134 漂成 268×60@(991,67)，面板报废需杀服务自愈）；电池
已改为逐窗 SC_MINIMIZE/SC_RESTORE，不再触碰面板。
