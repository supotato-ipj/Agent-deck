# Spec: TERMINAL 02 HUD 头显透视改造

Status: ready-for-agent

## Problem Statement

用户希望桌面壁纸的信息呈现有"透过 HUD 头显头盔观察"的沉浸感：信息模块带近大远小的透视，仿佛头盔内的环绕显示屏。壁纸内置的 perspective 开关只有 ±1deg 的固定微旋转，完全达不到这种观感；同时用户不再需要曾经显示分辨率/鼠标坐标/按键事件的鼠标指示器模块，它在桌面上是噪音。此前"恢复山脉背景"的诉求正式撤销。

## Solution

增强壁纸内置的 perspective 属性分支：开启后左右两栏整体做座舱环抱（绕垂直轴反向旋转、外缘退远），两栏下部信息块组追加仪表俯倾（绕水平轴后倾），并叠加头部视差——鼠标位置微调视角、指数平滑、静止时渐近回正，模拟头盔内转头。同时移除鼠标指示器模块的显示（保留其鼠标监听供视差复用）。HUD 模式仍由壁纸设置里的 perspective 开关控制，可随时关闭回到平面。

## User Stories

1. 作为桌面用户，我想在壁纸设置里用一个开关启用 HUD 模式，以便随时在头显观感与平面观感之间切换。
2. 作为桌面用户，我想看到左右两栏信息模块外缘退远、近大远小，以便获得座舱环抱的空间感。
3. 作为桌面用户，我想看到两栏下部信息块组像头盔仪表板一样后倾，以便强化"低头看仪表"的视角暗示。
4. 作为桌面用户，我想让视角随鼠标位置微微转动，以便模拟头盔内转头的动态感。
5. 作为桌面用户，我想让视角转动顺滑不抖动，以便长时间观看不疲劳。
6. 作为桌面用户，我想在鼠标静止数秒后视角自动回正，以便构图不长期歪斜（例如看视频时鼠标不动）。
7. 作为桌面用户，我想让视差偏移有幅度上限，以便移动鼠标到屏幕边缘时画面不失真。
8. 作为桌面用户，我想在关闭 HUD 模式后完全回到平面布局且无残留偏移，以便需要严肃阅读信息时不受透视干扰。
9. 作为桌面用户，我想让鼠标指示器模块（分辨率/坐标/按键事件）从界面上消失，以便右栏只留有价值的信息。
10. 作为桌面用户，我想让天气模块在鼠标指示器移除后保持原样，以便不损失已有信息。
11. 作为桌面用户，我想让头部视差在鼠标指示器移除后仍然工作，以便删模块不影响 HUD 动态。
12. 作为桌面用户，我想让背景保持现有深色抽象图不变，以便透视成为唯一的新视觉焦点。
13. 作为桌面用户，我想让 HUD 模式在被窗口遮挡后恢复显示时状态正确（不残留错误角度），以便切回桌面总是正确画面。
14. 作为壁纸维护者，我想让透视参数集中在少量常量中，以便日后微调角度不必理解全部代码。
15. 作为壁纸维护者，我想在创意工坊更新覆盖壁纸后能用重打补丁脚本恢复包括 HUD 改造在内的全部定制，以便不丢工作。

## Implementation Decisions

- **入口复用**：增强壁纸内置 perspective 布尔属性分支作为 HUD 模式唯一开关；不新建 CSS 层、不新增属性。属性为假时两栏 transform 为 none（平面）。
- **座舱环抱**：左栏绕垂直轴正向旋转、右栏反向，角度常量 8deg；变换原点沿用现有左/右栏设定。
- **仪表俯倾**：两栏下部信息块组（不含顶部标题）追加绕水平轴 3deg 后倾；与栏级旋转嵌套生效。
- **头部视差**：鼠标 X 相对屏幕中心的偏移驱动 rotateY 附加偏移（钳制 ±1.5deg），Y 驱动 rotateX 附加偏移（钳制 ±1deg）；在 requestAnimationFrame 循环中以指数平滑（系数约 0.08）逼近目标；鼠标静止超过数秒（常量约 3s）后目标归零，视点渐近回正。
- **监听复用**：移除鼠标指示器的 DOM 元素与显示更新代码，但保留 document 级 mousemove 监听作为视差输入源。
- **深度线索**：仅几何变换，不加亮度渐隐、装饰框或扫描线。
- **作用域**：左右两栏整体（含顶部标题）参与座舱环抱；仪表俯倾仅作用于下部信息块组。
- **背景**：保持壁纸包内深色抽象图，不做任何背景改动（山脉背景诉求撤销）。
- **常量集中**：环抱角、俯倾角、视差钳制值、平滑系数、静止阈值以命名常量集中定义。
- **交付管线**：沿用既有补丁目录与重放脚本；改动后需通过 Wallpaper Engine 的 openWallpaper 控制命令重载才生效（WE 不热重载网页壁纸）。

## Testing Decisions

- **唯一接缝**：浏览器中打开的壁纸页面。变换接缝 = 左右栏元素的 inline transform：注入 perspective 属性真值后断言含 ±8deg 环抱与 3deg 俯倾；向屏幕边缘派发 mousemove 断言附加偏移被钳制；静止超过阈值断言渐近回正；属性假值断言 transform 为 none。
- **DOM 契约**（同一浏览器会话内断言）：鼠标指示器的分辨率/坐标/按键事件元素不存在；document 级 mousemove 监听仍存在并驱动视差状态（派发事件后 transform 变化）。
- 好的测试只断言外部可观察行为（transform 字符串/DOM 存在性），不断言内部变量。
- **视觉验收**：桌面截图（最小化窗口→截图→还原脚本）确认 HUD 开/关两种状态；用户在 Wallpaper Engine 中最终过目。

## Out of Scope

- 亮度/透明度深度渐隐、HUD 装饰元素（角标、扫描线、准星）。
- 背景更换或纯黑化。
- 视差的垂直轴单独开关、用户可调角度参数（WE 属性面板不新增项）。
- 天气模块的任何改动。
- Qoder 状态块与数据服务的功能变更（已在上一 feature 交付）。
- 开机自启数据服务（仍为待办，与本 feature 无关）。

## Further Notes

- 词汇以根目录 CONTEXT.md 为准：HUD 模式、座舱环抱、仪表俯倾、头部视差、信息模块；"鼠标指示器"已登记为退役词汇。
- 环境事实：WE 被窗口遮挡时暂停壁纸页定时器与 rAF，恢复显示时循环重启——回正逻辑需在循环重启后仍收敛（目标角由当前鼠标位置重算，天然满足）。
- 本 feature 的决策不满足 ADR 三条件（可逆、不惊人、无重大权衡），不另立 ADR。

- 2026-09-20 用户反馈迭代：角度 8/3deg 过大不可读 → 降至 30%（2.4/0.9）→ 再减半（1.2/0.45）；头部视差先降至 1/4 后应用户要求整体移除，HUD 模式现为纯静态透视（CONTEXT.md 已登记退役）。
