## 为什么不删

留档不是为了将来恢复，而是为了让「壁纸曾经长在这里」这件事在仓库里可查：
DECIMA Mono 等商业字体、`preview.gif`、原版 `performance.layout.js` 一旦删除，
就只能从创意工坊重新下载才能取回。**封存不等于可用**——这些文件不再随任何构建、
测试或验收流程运行，也不再被代码引用（可 `grep` 自证：仓库中除本目录与历史票据外无引用）。

## 处置约定

- **不改**：任何修复、重构、格式化都请不要落到本目录。
- **不依赖**：新功能不得引用这里的字体或资源。需要字体请走 `app/` 自己的资产目录
  （字体选型见 `.scratch/standalone-app/spec.md` 的「字体」决策：可商用免费候选，本地化随应用分发）。
- **可删**：若日后确认永不再需要，整目录删除即可——历史仍在 git 里，不必担心追溯。
