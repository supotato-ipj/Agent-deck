# Files

- [Integration: the five AI tool on-disk stores](agent-tool-stores.md) - The upstream storage surfaces the five session scanners read read-only and without upstream cooperation: per-tool root paths, on-disk layouts (a JSONL append log, two unrelated SQLite schemas, a per-session directory tree, two flat status maps with no plaintext titles), how liveness is judged for each, what degrades when a store is missing, locked or reshaped, and the version fragility of formats this repository does not own.
- [Integration: Listary 7 local HTTP search API](listary-engine.md) - The external search contract as the panel's kernel consumes it: POST /api/v1/search on a loopback host with a configured port, the query/limit/offset body, the ok/data.results mapping into SearchResultItem, the offline/rate-limited/error taxonomy, and the no-CORS, no-keep-alive transport with a 3 s timeout that keeps engine I/O in one client.
- [Integration: background layer and the retired Wallpaper Engine toolchain](wallpaper-engine.md) - The wallpaper is now only the background layer the panel floats over — never built, deployed, patched or polled by this repository — after the Wallpaper Engine deployment/patch toolchain and the Python data service were retired on 2026-09-29 and their assets frozen read-only under archive/.
- [Integration: Windows shell, registry and native APIs](windows-shell-and-system-apis.md) - The inventory of operating-system surfaces the panel touches, split by direction — the ones it writes to (explorer's desktop icon view through the shell view command, the Startup folder link through a PowerShell COM helper, other applications' window state, its own files and spawned helpers) and the ones it only reads (process and window enumeration, registry queries and exports, file attributes, interface counters, nvidia-smi) — with each koffi binding's DLL and calling convention, each helper's encoding constraints, and the ADR-0002 rule that no window title is ever read.
